### Hexo 简介

Hexo 是一个快速、简洁且高效的博客框架。它基于 Node.js，可以将 Markdown 文件快速生成静态网页。

### 主要特点

- **快速** - 生成静态文件速度极快
- **简单** - 只需几条命令即可部署博客
- **高效** - 支持多种主题和插件
- **Markdown** - 使用 Markdown 语法编写文章

### 开始使用

```bash
# 创建新文章
hexo new "文章标题"

# 生成静态文件
hexo generate

# 启动本地服务器
hexo server

# 部署到远程
hexo deploy
```
