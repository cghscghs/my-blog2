# 这是一篇演示如何插入图片的文章

大家好！这篇文章将演示如何在 Hexo 博客中插入图片。

<!-- more -->

## 方法一：使用文章资源文件夹（推荐）

下面是一张放在文章同名文件夹中的图片：

![示例图片](牛逼666/示例图片.jpg)

这张图片存放在：`source/_posts/牛逼666/示例图片.jpg`

### 这种方法的优点：
- ✅ 图片和文章放在一起，便于管理
- ✅ 不用担心路径问题
- ✅ 删除文章时可以一并删除图片

## 方法二：使用网络图片

直接引用网络上的图片：

![网络图片示例](https://picsum.photos/600/300)

语法很简单：
```markdown
![图片描述](图片URL)
```

## 方法三：统一图片文件夹

如果你有很多文章要用同一张图片，可以把图片放在 `source/images/` 文件夹：

```markdown
![公共图片](/images/图片名.jpg)
```

## 小技巧

### 1. 调整图片大小

使用 HTML 语法可以控制图片大小：

```html
<img src="牛逼666/示例图片.jpg" width="400" alt="小图片">
```

效果如下：

<img src="牛逼666/示例图片.jpg" width="400" alt="小图片示例">

### 2. 图片居中

```html
<div align="center">
  <img src="牛逼666/示例图片.jpg" width="500" alt="居中图片">
</div>
```

### 3. 多图并排

<div style="display: flex; gap: 10px;">
  <img src="牛逼666/示例图片.jpg" width="300" alt="图1">
  <img src="https://picsum.photos/300/200" width="300" alt="图2">
</div>

## 总结

在 Hexo 中插入图片很简单，推荐使用 **文章资源文件夹** 的方式，这样图片和文章在一起，管理起来最方便！
